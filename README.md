# Insulator Workshop Tracker — v1

تطبيق متابعة إنتاجية العمّال (عربي / English).

## التشغيل
```
~/.local/bin/node server.js
```
ثم افتح http://localhost:5180 — أو من التابلت على نفس الواي فاي: http://<IP-الماك>:5180

## الحسابات الافتراضية (غيّرها من الإعدادات)
- المالك Karam: 0000 — كل شيء
- المشرف: 1111 — تسجيل السيارات وتشغيل الوقت فقط، بدون إحصائيات
- المدير: 2222 — مشاهدة الإحصائيات والتقارير فقط

## ملاحظات v1
- البيانات تُحفظ على الجهاز نفسه (localStorage) — استخدم جهاز ورشة واحد ونزّل نسخة احتياطية من الإعدادات ← البيانات.
- PDF / Excel / مشاركة واتساب وإيميل من صفحة "الأداء".
- الملفات: index.html · styles.css · app.js (كل المنطق) · sw.js (يعمل بدون إنترنت)
